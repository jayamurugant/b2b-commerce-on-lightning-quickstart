This release is in preview

Note: This release is in preview. Features described in this document don't become generally available
until the latest general availability date that Salesforce announces for this release. Before then, and
where features are noted as beta, pilot, or developer preview, we can't guarantee general availability
within any particular time frame or at all. Make your purchase decisions only on the basis of generally
available products and features.

The Spring ’26 release helps companies to accelerate their journey to becoming an Agentic Enterprise by
combining human expertise and AI agents — giving every team the insights, automation, and tools they
need to deliver better customer experiences with confidence.


What's New This Release

• Admin Release Countdown Blog. Important dates you’ll want to mark on your calendar for Spring '26.
• Spring '26 Pre-release Signup. Sign up for a pre-release org to get early access to the new features.

Release Readiness Essentials

• Release Readiness Trailblazers. Access resources and experts for all things release readiness. To help us
    track and respond to your feedback, use a hashtag that indicates the release, such as
    #Spring26Feedback.

    maintenance dates, select Instances and your instance.
•   Sandbox Refresh Calculator, Preview Video, and Preview Instructions. Plan if and when to refresh your
    sandboxes. Learn how to navigate the sandbox preview process. Get early access to new features in
    your sandbox.
•   Certification Release Maintenance Schedule. Keep your certification updated in Trailhead.
•   Prepare for Salesforce Releases. Use Trailhead to create your release strategy.

  Learn about new features and enhancements that affect your Salesforce experience overall.
  Release Updates
  Salesforce periodically provides release updates that improve the performance, logic, security, and
  usability of our products. The Release Updates page provides a list of updates that can be necessary
  for your organization to enable. Some release updates affect existing customizations.
  Agentforce Platform
  Supercharge your workforce efficiency with predictive and generative AI.
  Analytics
  Analytics enhancements include new and updated features for Tableau Next, Lightning reports and
  dashboards, Data 360 reports and dashboards, CRM Analytics, Intelligent apps, and Tableau.
  Commerce
  Commerce enhancements include features for B2B Commerce, Omnichannel Inventory, and
  Salesforce Order Management.
  Customization
  Complete Setup tasks more efficiently with the help of an AI assistant with Setup with Agentforce
  (beta). Import and export translation files more easily with enhancements to the Translation
  Workbench.
  Development
  Whether you’re using Lightning components, Visualforce, Apex, or Salesforce APIs with your favorite
  programming language, these enhancements help you develop amazing applications, integrations,
  and packages for resale to other organizations.
  Experience Cloud
  Make your Aura and LWR site pages more discoverable to AI-powered search engines and improve the
  precision of AI-generated answers with generative engine optimization. Create richer HTML content for

  Aura and LWR sites and enjoy greater design flexibility on LWR sites with expanded HTML allowlists
  and more readily available standard LWR components. Updates to Salesforce files make it easier for
  users to manage, delete, upload, and download files. The ability to create custom property types and
  editors for Aura and LWR sites is now generally available.
  Field Service
  See what’s new in Agentforce Field Service, formerly Field Service, to help your team deliver on
  performance and customer service.
  Hyperforce
  Products and features from Data 360, Marketing Cloud, Platform, MuleSoft, and Tableau Cloud are
  now available in more Hyperforce regions. Hyperforce Assistant introduced a new way to find hard-
  coded references. The Hyperforce public IP ranges now include addresses for inbound connections, in
  addition to existing outbound addresses. Prepare for IPv6 if you use IP allowlists.
  Industries
  Learn about new features and enhancements across the Industries clouds.
  Marketing
  Personalize every moment of engagement across the customer lifecycle and drive growth for your
  business with the latest features and enhancements from Salesforce Marketing apps.
  MuleSoft
  Use the MuleSoft Anypoint Platform suite of products to connect and integrate apps, systems, and
  data across your enterprise. Streamline operations by building and automating processes with clicks
  instead of code. You can design, develop, govern, and share APIs and integration apps and host them
  in the cloud or on-premises.
  Mobile
  The Salesforce mobile app now uses single sign-on for faster logins and notifications that lets you work
  on tasks. Create mobile and offline ready Lightning Web components with Mobile MCP tools.
  Omnistudio
  Validate your workflows built with Omniscripts and Flexcards end-to-end by using the UI Test
  Automation Model (UTAM) framework. For a fast, scalable experience, add Omnscripts and Flexcards
  to Lightning Web Runtime (LWR) Experience Cloud sites (pilot). Get immediate help with an
  Omnistudio component or element with the Omnistudio Assistance AI Agent (pilot). With accessibility
  improvements for Omniscripts and Flexcards, create inclusive workflows and solutions for customers
  and users with disabilities. Filter empty records in Omnistudio Data Mapper Extract and Turbo Extract
  components with the Is Null operator.
  Partner Cloud
  Start managing the full partner lifecycle in one place with tools built directly into Salesforce. Use
  Partner Cloud to recruit, onboard, enable, and co-sell with partners while giving them secure access to
  the data and workflows they need. Bring together key capabilities like deal registration, incentives,
  training, and performance tracking so your team can scale indirect sales and improve partner
  relationships. Partner Cloud helps you do more with the partners you already have—faster, and with
  less manual work.
  Revenue Management
  Learn about new features and enhancements for Agentforce Revenue Management.
  Sales

  Salesforce CMS
  Previously known as Sidebar Extensions, Extensions in CMS have an improved development workflow.
  Build extensions to add more productivity tools to your CMS content workflow, such as third-party

  Service Cloud is now Agentforce Service. You may see references to Service Cloud in our application
